## code
    
- open je arduino IDE
- open je sketch:
            - les2-getallenbende
    

## code

- Maak 4 variabelen aan.
    - A, B , C en  D
    - van het type int

- Geef ze een willekeurige waarde met:   
    > = random( 999 );

- maak nu een if else structuur:
    - Zet D3 aan wanneer A groter is dan B, of als A kleiner is dan C
        > hint:
        > - voor EN gebruik je &&
        > - voor ALS gebruik je ||
    - Zet D5 aan wanneer C groter is dan A en A kleiner is dan B
    - Zet D6 aan wanneer B groter is dan C en B groter is dan A en C kleiner is dan A
    - Laat alle lampen snel knipperen wanneer D het grootste getal is.
- Doe dit elke 2 seconden.

- Check of je code klopt door de waardes te printen in de Serial!
